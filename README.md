## PUPPACCINO

Puppaccino es una página web ficticia para una cafetería solidaria
orientada al cuidado y adopción de perros rescatados. Este proyecto fue
desarrollado como pre-entrega para el curso de Front-End.

El sitio cuenta con un diseño responsivo y una navegación fija e interactiva.
Permite conocer el catálogo de productos de la cafetería, ver la galería de
perros disponibles para adopción, conocer el proyecto y enviar consultas
mediante un formulario de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Formspree
